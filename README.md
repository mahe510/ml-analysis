# ML Analysis Portfolio

This repository hosts my **Machine Learning Portfolio Website**, built to showcase multiple end-to-end ML projects in a clean and structured way.

The portfolio presents each project with:
- Problem statement
- Dataset description
- Analysis steps
- Models used
- Final results
- GitHub repository links

The website is built using **HTML, CSS, and JavaScript** and is deployed using **GitHub Pages**.

---

## 🌐 Live Portfolio

👉 **Live Website:**  
https://mahe510.github.io/ml-analysis/

---

## 📂 Projects Included

- **Customer Segmentation**
  - Clustering customers based on spending behavior
- **Fake News Detection**
  - NLP-based classification of fake vs real news
- **Student Learning Drop-off Prediction**
  - Predicting student dropout risk using engagement data
- **Titanic Survival Prediction**
  - Predicting passenger survival using classification models
- **Twitter Sentiment Analysis**
  - Sentiment classification on large-scale Twitter data

Each project is dynamically loaded using JSON files to keep the website scalable and maintainable.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Machine Learning:** Python, Pandas, NumPy, Scikit-learn  
- **NLP:** NLTK, TF-IDF  
- **Deployment:** GitHub Pages
